# OWASP NodeGoat - DevSecOps Pipeline
 
**IE3142 DevOps Security Assignment**  
 
This repository contains OWASP NodeGoat with an integrated DevSecOps CI/CD pipeline featuring automated security gates (SAST, Dependency, Secrets, and Container scanning).
 
---
 
##  Project Overview
 
**Objective**: Demonstrate secure software development practices through:
1. **Threat Modelling** (STRIDE analysis)
2. **Vulnerability Exploitation** (4+ OWASP Top 10 vulnerabilities)
3. **Secure Coding Fixes** (with before/after SAST validation)
4. **DevSecOps Pipeline** (automated security gates)
**Tech Stack**:
- **Runtime**: Node.js 14 LTS
- **Framework**: Express.js 4.x
- **Database**: MongoDB 4.4
- **Containerization**: Docker & Docker Compose
- **CI/CD**: GitHub Actions
- **Security Scanning**: Semgrep, npm audit, Gitleaks, Trivy
